# CalcLab — Scientific Calculator

A responsive scientific calculator made with plain HTML, CSS and JavaScript. No framework or build step is required.

## Run locally
Open `index.html` in a web browser.

## Deploy to Netlify with GitHub
1. Create a new GitHub repository, for example `calclab`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In Netlify, choose **Add new project / Import an existing project** and select GitHub.
4. Select the repository.
5. Leave the build command empty and set the publish directory to `.` (root).
6. Deploy. Future pushes to the connected production branch trigger automatic deployments.

## Features
- Basic arithmetic, parentheses, percentages and powers
- Trigonometric functions with DEG/RAD toggle
- Square root, logarithms, pi, Euler's number, factorial and previous answer
- Responsive layout for desktop and mobile

This is a beginner-friendly starter project. Check results for important calculations before relying on them.
